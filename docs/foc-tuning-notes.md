# STM32 FOC 调试记录（电流环 / 电角度外推 / 速度环 / 位置环）

记录本板 FOC 从"电流环调不通"到"三层闭环可用"的全过程：每个问题的**现象 → 根因 → 做法 → 验证数据**。
所有数据都是本机实测（串口抓取），不是估算。

---

## 1. 硬件与总体结构

```
                 ┌──────────────────────────────────────────┐
   12V 母线 ─────┤ 3 个半桥（TIM1 CH1/2/3: PA8/PA9/PA10）    │
                 └───────┬──────────────┬─────────────┬─────┘
                         │              │             │
                    U 相低端分流    V 相低端分流      W 相（由 ia+ib 推出）
                    5mΩ + INA240A2  5mΩ + INA240A2
                         │              │
                    ADC 注入组 rank1   rank2        ← 由 TIM1 CH4(无引脚) 触发
                    (CHANNEL_5/PA5)  (CHANNEL_4/PA4)
                         │              │
              ┌──────────┴──────────────┴────────────┐
              │ ADC 注入转换完成中断 = 电流环 20kHz ISR │
              └───────────────────┬──────────────────┘
                                  │
   AS5600 磁编码器(12bit, I2C1 PB6/PB7, 400kHz) ── 主循环每 5ms 读一次
                                  │
   USART2 (PA2/PA3, 115200) ── CLI 命令 / 调试打印 / VOFA
```

**采样时序（关键）**

| 项 | 值 |
|---|---|
| PWM | TIM1 中心对齐，ARR=2100-1，定时器 84MHz → **20kHz**，占空比 = 比较值/ARR |
| 注入触发 | CH4 = PWM2 模式，CCR4=1799（无引脚输出）→ 采样点落在"三路全低"窗口内且靠近中心 |
| 注入转换 | 2 通道 × 84 周期采样 + 12 周期转换，ADC 时钟 21MHz → 一次 **9.1µs** |
| ISR | 注入转换完成中断，**20kHz**（第二次 CC4 匹配时 ADC 忙，被忽略，保证节拍稳定） |
| VOFA | 每 100 个 ISR 送一帧 → **200Hz** |
| 编码器 | 主循环每 5ms 读一次 → 角度用它，但 ISR 里用电角度外推补齐（见 2.6） |

**三层闭环**

```
位置环  波特 ~0.5Hz   PID_P 3 1        → 输出速度给定 (rad/s)
   ↓                                  （死区 ±0.02rad，见 2.9）
速度环  波特 ~2.5Hz   PID_S 0.001 0.005 + 摩擦前馈 FF 0.03 → 输出 iq_ref
   ↓                                  （限幅 ±0.6A）
电流环  波特 ~600Hz   PID_D/Q 2 10000  → 输出 vd/vq
   ↓                                  （限幅 ±6V，实际再被 span 限幅压到 ~4V）
SVPWM → 占空比 → 定时器
```

带宽阶梯 0.5 → 2.5 → 600 Hz。**调外环时内环参数必须冻结**，改内环后外环要重调。

## 2. 关键处理点

### 2.1 电流采样：相序映射与符号

- **现象**：id 环路波形反向；电流与施加电压对不上。
- **根因**：注入组通道顺序与 PWM 相的对应关系搞反；INA240 输出极性与"电流流入电机为正"的约定相反。
- **做法**
  - 注入组 `rank1 = ADC_CHANNEL_5(PA5)` 对应 `TIM1_CH1(PA8)` 那一相；`rank2 = ADC_CHANNEL_4(PA4)` 对应 `TIM1_CH2(PA9)` 那一相（与硬件接线一致，**不要按直觉换**）。
  - `CURRENT_SENSE_SIGN = -1.0f`（本板 INA240 接法）；改硬件极性后必须改回 +1，否则又反一次。
  - `current_c = -current_a - current_b`（三相无中线，只测两相）。
- **验证**：开环 θ=0、Vq>0 时 a 相≈0、b 相为正、c 相为负；`ID 0.3` 时转子不转（见 2.2）。

### 2.2 电流零点对齐（ALIGN 必须等转子真的静止）

- **现象**：纯 d 电流也会推动转子；电流环大超调且对 kp 不敏感。
- **根因**：原来固定 500ms 后读一次角度当零点。而转子被磁场拉到位置后会在 ~19Hz 上欠阻尼振荡，中途读数会把零点偏几十度。
- **做法**：500ms 之后**每 50ms 读一次**，连续 3 次变化 < 5mrad（≈150ms）才判稳定并锁存零点；最长等 3s 兜底。
- **验证**：对齐后 `ID 0.3` → 转速 0.00 rad/s、`ID` 跟踪 0.298/0.3 ✓；`ALIGN: done, offset=5.245 (t=650ms)`。
- **注意**：`ALIGN` 命令只在状态机 `CALIBRATING → ALIGN` 阶段生效，跑过一次后必须**复位**才能重新对齐。

### 2.3 低端分流采样窗口 → SVPWM span 限幅（可用电压只有 ~4V）

- **现象**：低占空比侧采不到电流；大电流时电流波形失真；"到 1.2A 上不去"。
- **根因**：低端分流只能在**三路全低（零矢量）**窗口内采样，而该窗口宽度 = `(T/2)·(1 - span/Vbus)`，span 是三相电压的最大最小差。调制越深窗口越窄。
- **做法**：在 `foc_svpwm()` 里限制 span：
  ```
  span_limit = Vbus × (1 - 2×10.6µs/50µs) ≈ 0.576 × Vbus
  ```
  10.6µs = 两路注入转换 9.1µs + 1.5µs 余量。span 相对矢量幅值随电角度在 1.5~√3 倍之间变化，
  所以**等效可用矢量电压 ≈ 4.6V（最佳角度）~ 4.0V（最差角度）**，12V 母线下堵转电流上限 ≈ **1.16A**。
- **验证**：0.5A 堵转时 vq=1.75V、|V|≈1.75V（远未限幅 ✓）；SPD 限幅在 1290rpm 附近出现。
- **重要**：限幅削的是"实际施加"的电压，`motor2_vd/vq` 仍是 PI 需求值，**看 VOFA 上的 vd/vq 看不出限幅**，要看电流是否还跟得上。

### 2.4 ADC 采样时间与注入触发点

- 采样时间 **84 周期**（96 个 ADC 周期含转换，@21MHz ≈ 4.57µs/通道），两通道合计 9.1µs。
- CC4 = **1799**：中心对齐下上下坡各匹配一次，两次相隔 2×(2099-1799)/84MHz = 7.1µs < 9.1µs，
  第二次触发时 ADC 仍忙而被忽略 → ISR 稳定 20kHz，采样点均匀落在窗口中心偏后。
  （取 1715 时两次匹配正好隔 9.1µs，实测 ISR 变成 ~20.3kHz、采样点不均，所以不取。）

### 2.5 电流反馈滑动平均（MA8）

- **现象**：iq 显示带宽 ±4~8%，且调 PI 参数完全无效。
- **根因**（实测定位）：把 PI 增益设 0（环路不动作、电机无电流）后，**带宽一模一样** → 说明不是环路问题，是采样链自己的噪声：
  - **分辨率**：`1 LSB = 3.3V/4095 ÷ (5mΩ×50) = 3.2235 mA`（原始读数必然是它的整数倍，实测 56/61/62/66 计数）
  - **噪声**：每相读数抖动 3~6 LSB，且**相邻样本相关（lag-1 ≈ 0.66）** → 带限噪声（相关时间 50~100µs），不是白噪声
- **做法**：对 ia/ib/ic 做 **8 点滑动平均**（`CURRENT_LPF_N 8`）：噪声 ÷2、群延迟 175µs、200Hz 处滞后 12.6°。
  滤波放在 Clarke 之前（噪声进来的地方），浮点平均还能给出**亚 LSB 分辨率**。
- **验证**

  | 指标 | 无滤波 | MA4 | MA8 |
  |---|---|---|---|
  | 纯测量链 std（环路关） | — | 1.47 LSB | **1.11 LSB** |
  | 纯测量链峰峰 | — | 8.9 LSB | **5.6 LSB** |
  | 显示的 iq 峰峰（0.5A） | 0.0393 A | 0.0201 A | **0.0194 A** |
  | vq 峰峰 | 0.231 V | 0.131 V | **0.053 V** |

  → **显示的带宽 1:1 等于测量链底噪**（环路关掉测出来一样），所以那 ±4% 是"仪表分辨率"，不影响力矩。
- **进一步**：加不动了 —— 噪声是相关的，8→16 点只再降 1.3× 却要吃 27° 滞后。
  真要更低只能动硬件：**把 5mΩ 换成 20mΩ**（信号×4、放大器输入噪声不变 → 折合电流噪声 ÷4）；
  光换高增益型号（INA240A4）只改善量化，不改善 SNR。

### 2.6 电角度外推（编码器 5ms → ISR 20kHz）

- **现象**：锁轴时电流环干净（1.5 LSB），**转子一转就废**：id std 40 LSB、iq std 31 LSB，
  频谱出现 200/400/600Hz 线谱（正好是 5ms 更新率的谐波）。
- **根因**：ISR 直接复用主循环写下的电角度，最坏滞后 5ms。转起来后 δ=ω_e×5ms 就是几十度，
  电流被施加在错误的坐标上。
- **做法**
  - 主循环每次成功读到角度：记下 **(机械角, TIM2 计数)**，并用两次读数差估机械角速度
    （回绕修正 + 一阶低通 α=0.25 ≈ 20ms + 钳位 ±300rad/s）。
  - ISR 里：`θ_e = f(机械角_ref + ω·Δt)`，Δt = `TIM2->CNT - ref_cnt`（TIM2 自由运行 84MHz，51s 回绕，
    无符号相减天然处理回绕）。
  - **保护**：主循环被 UART dump 阻塞时 Δt 会很大，外推**钳位到 10ms** 并计数（`EXTRACLIP`）。
- **验证**（IQ 0.1、自由转子 1481rpm，此工况电压有余量所以测的是角度质量）

  | 指标 | 改前 | 改后 |
  |---|---|---|
  | iq std | 31 LSB | **4.22 LSB** |
  | id std | 40 LSB | **3.24 LSB** |
  | 400Hz 线谱 | 0.10 | **0.0076** |

### 2.7 电流环 PI（零极点对消）

- 参数 **kp=2, ki=10000**（d/q 相同），输出限幅 ±6V。
- 依据：`ki/kp = 0.2ms = L/R`（实测 R≈3.5Ω、L≈0.68mH）→ 对消电机电气极点。
- 实测：稳态误差 ≤1%（0.1A/0.5A 两点）、上升 0.25~0.30ms、kp=2 时超调 ~25%；
  `vq/iq = 3.5Ω`、`L/R = 0.2ms` 与独立测量自洽。
- **标定 q 轴动态时转子必须刚性固定**：自由转子时反电势和转动会污染阶跃波形（实测角度漂 1rad、超调虚高到 56%）。

### 2.8 速度环

- **参数**：`kp = 0.001 A/(rad/s)`、`ki = 0.005 A/(rad/s²)`、输出限幅 ±0.6A。
  实测（30rad/s 阶跃）：**上升 ~400ms、超调 4%、稳态误差 −0.2%、波动 ±1%**。
- **量级警告**：默认值给 0.02/0.1 时**必震**。本机机械阻尼极小：
  - 纯积分（kp=0）也会震 —— 近纯惯量对象上积分 = 双积分器，相位天生 180° → 极限环
  - kp=0.005 开始高频振荡；kp/Kt·B 的平坦段环路增益必须 <1（kp < B/kt ≈ 0.003）
  - 所以**别凭直觉往上加**，用 `CAPS` 抓 2s 波形按超调/波动扫
- **摩擦力前馈（FF）**：静摩擦门槛实测 **0.019A**（`SPD 2` 时 2 秒转速都是 0、iq 才爬到 0.0185；
  `SPD 5` 先静止 1s 再一下冲到 7.7rad/s）。前馈把电流一开始就顶过门槛 → 起步从"2 秒不动"变成 **70ms**。
  - 但前馈必须**随 |速度给定| 渐升**（0.05→0.5 rad/s 内插值）：满幅 0.03A 比摩擦门槛还大，
    若在目标附近一直满幅，会把转子顶得来回蹭（实测位置环稳态 ±5rad/s 摇摆）。
- **限幅链**：电流环 ±6V → SVPWM span 限幅 ~4V → 速度环 ±0.6A。

### 2.9 位置环

- **参数**：`kp = 3 1/s`、`ki = 1 1/s²`、输出限幅 ±40 rad/s、**死区 ±0.02 rad（≈1.15°）**。
- **命令语义**：`POS x` = 相对当前位置再转 x 弧度（正方向与 `SPD` 一致）→ 免去"绝对角是多少"的困惑，
  而且**相对指令天然免疫累圈误差**（见下）。
- **必须自己累圈**：编码器只给单圈 12bit 值。主循环每次成功读到时把"回绕修正后的增量"累加到 `pos_mech`。
- **误差按 ±π 回绕**：跨圈时走最短路径。
- **安全：圈数不可辨就判失效**。读数间隔 > 30ms（主循环被 UART dump 阻塞）时，这期间转过几圈不可知
  → `POS_VALID=0` 并自动退出位置环（否则可能驱动到"差一整圈"的错误目标）；`POS_GAP_CNT` 计数；
  再发一次 `POS x` 即可重新锚定恢复。
- **死区（消除极限环的关键）**：死区内输出 0 速度给定，**并把内环积分也清掉**
  （否则速度环积分会慢慢把电流顶到摩擦门槛、又蹭起来）。

- **实测**

  | | 修死区前 | 修后 |
  |---|---|---|
  | 稳态速度摆动 | **±5 rad/s**（来回蹭） | **0.000 ± 0.024 rad/s** |
  | 稳态 iq | 0.029 A（一直顶摩擦门槛） | **−0.0003 ± 0.0026 A** |
  | 小阶跃 0.3rad 残差 | ±2° 抖 | **+0.07°** |
  | 大阶跃 1.571rad 残差 | — | **−1.03°** |
  | 1.571rad 阶跃上升(10→90%) | — | **205ms**，超调 ~8° |

- **已知特性**：死区内保持力矩为 0（靠摩擦站住）。平衡负载没问题；偏心/受重力负载会滑到死区边缘才被拉住，
  静态误差最大 ±1.15°。要更硬需加齿槽补偿表。

### 2.10 PWM 启停：绕开 HAL 的通道状态机

- **现象**：反复 start/stop/fault 后 `HAL_TIM_PWM_Start` 返回 HAL_ERROR 且不使能输出 → `RUN: pwm start fail` + FAULT，PWM 永远起不来。
- **根因**：F4 HAL 在启动时检查"通道状态"簿记，簿记与硬件不一致时就拒绝。
- **做法**：直接寄存器操作 —— `motor2_pwm_set_duty(0.5)` → `TIM_CCxChannelCmd(ENABLE)` ×3 → `__HAL_TIM_MOE_ENABLE` → `__HAL_TIM_ENABLE`；停止时先比较值归零再关通道、最后关 MOE（避免半桥直通）。

### 2.11 I2C 鲁棒性

- **根因**：10k 上拉 + 400kHz 时上升时间超标 → 字节中途出错 → 从机停在半个字节里拉住 SDA → 之后每次调用都在传输开始前返回 `HAL_BUSY(st=2)` 且不自恢复。
- **做法**：降到 400kHz 需 2.2k 上拉（当前配置）；写了 `as5600_bus_recover()`（9 个慢时钟 + STOP + 外设复位重初始化）。
- **判故障用"连续失败次数"而不是"距上次成功的时间"**：主循环被阻塞时压根没发起读取，用时间判会误报；连续 6 次先自愈，20 次才判 FAULT。

## 3. CLI 命令

| 命令 | 说明 |
|---|---|

| `PID_P kp ki` | 位置环参数，单位 1/s、1/s² |
| `SPD x` | 速度环给定（rad/s 机械），自动退出位置环 |
| `SPD_OFF` | 关速度环并把 iq_ref 归零 |
| `FF x` | 摩擦力前馈（A），默认 0.030，`FF 0` 关闭 |
| `POS x` | 位置环：相对当前位置转 x 弧度（自动打开速度环） |
| `POS_OFF` | 关位置环 |
| `STATUS` | 状态号/角度/电流/电流给定/转速/速度给定/FF/位置/位置给定/位置误差/各使能/EXTRACLIP |
| `CAP` | 抓电流环波形：**50µs × 400 点 = 20ms**，触发条件=发一次 `ID`/`IQ` |
| `CAPS` | 抓速度/位置环波形：**5ms × 400 点 = 2s**，触发条件=发一次 `SPD`/`POS` |
| `VOFA ON/OFF` | 200Hz JustFloat 输出（7 通道，见 vofa.c） |
| `OPENLOOP` / `CLOSELOOP` / `OL_SPEED x` / `OL_VOLT x` | 开环调试 |
| `HELP` | 命令列表 |

**状态号**：0=CALIBRATING 1=ALIGN 2=READY 3=RUNNING 4=OPENLOOP 5=FAULT

## 4. 上位机工具与验证方法

`Tools/serial/`（Python + pyserial，COM7@115200）：

| 脚本 | 用途 |
|---|---|
| `enc_probe.py` / `diag_all.py` | 只读探测：编码器/ISR 频率/I2C 引脚电平/状态机 |
| `ripple_diag.py` `cap_save.py` `cap_analyze.py` | CAP 抓取 + 时域/频域分析（判断噪声 vs 振荡） |
| `ma8_check.py` `gain_test.py` | 用"环路关"对照测纯测量链底噪（本记录 2.5 节的方法） |
| `extrap_verify.py` | 验证电角度外推（低电流自由转动下测角度质量） |
| `speed_start.py` `speed_test.py` `speed_sweep.py` `speed_sweep2.py` | 速度环阶跃/扫描（带发散保护） |
| `decode_frames.py` + `frames_*.txt` | 解析 VOFA JustFloat 帧（含 LSB 格点检查） |

**几个可复用的判据**

1. **"是不是采样噪声？"** 把 `PID_D/PID_Q` 设 0（环路不动作、无电流）再测同一工况 —— 带宽一样就是采样链。
2. **"显示值是不是量化格点？"** 除以 `1 LSB = 3.2235mA`，是整数 → 原始未滤波；出现小数 → 滤波生效。
3. **"波动是白噪声还是低频？"** `相邻样本差 std / (√2·std)`：≈1 白噪声、<<1 带限/振荡。
4. **"转子到底动没动？"** 隐含反电势 = `vq均值 − R·iq均值`，≈0 静止、明显非 0 在转。
5. **"是不是电压顶到头？"** 转速不再随电流上升 + 实测 iq < 给定 + vd/vq 顶在 ±6V。

| 1 | **UART 接收溢出后接收链静默断掉**（F4 HAL 在 ORE 后不再自动重挂 RX，固件无 `HAL_UART_ErrorCallback`） | 命令偶尔被吞（调试时很迷惑） | 加 ErrorCallback：清标志 + 重新 `HAL_UART_Receive_IT`（约 6 行） |
| 2 | **`CAP`/`CAPS` 的 dump 阻塞主循环 1.2~1.9s** | 期间编码器停更新、外推被钳位、速度/位置环用陈旧反馈；`POS_VALID` 会失效 | 改成分片非阻塞发送 |
| 3 | **`ALIGN` 只在复位后的 ALIGN 阶段可执行** | 跑过一次后不能重新对齐 | 允许 READY 状态下重新 ALIGN |
| 4 | **极低速（<5 rad/s）爬行** | 齿槽+静摩擦导致的"一顿一顿" | 齿槽补偿表（慢转一圈标定电流 vs 电角度） |
| 5 | 位置死区内保持力矩为 0 | 偏心负载有 ±1.15° 静差 | 齿槽补偿表，或减小死区 |
| 6 | 电流测量底噪（1.1 LSB rms @MA8） | 显示带宽 ±4% | 换 20mΩ 采样电阻（比换高增益型号更对症） |
| 7 | 速度环低速段反馈粗（12bit 编码器 @5ms 差分） | 低速分辨率差 | 改用电角度估速（分辨率 ×7） |
| 8 | `SPD_EN 1A` 这类显示错乱 | 无（VOFA 二进制帧插进 ASCII） | 发 `VOFA OFF` 即可 |
